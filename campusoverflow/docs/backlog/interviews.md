# 用户访谈记录（L3 课后作业）

> 负责人：PO    要求：≥ 3 份真实访谈，覆盖学生 / 助教或研究生 / 教师
> 规则：**只记录过去发生的事实与原话，不记录自己的评价，不问"你想要什么功能"**

## 访谈提纲（20–30 分钟）

1. 最近一次你在课程学习中卡住，具体是什么问题？
2. 当时你怎么找答案？找了多久？用了哪些渠道？
3. 最让你烦躁的是哪一步？
4. 你问过助教或老师吗？用什么方式？多久得到回复？
5. 你有没有帮别人解答过？那次体验如何？
6. 如果答案有好有坏，你怎么判断哪个可信？
7. 你会在意自己的提问被同学看到吗？为什么？
8. 你们课程的答疑记录现在留存在哪里？以后还能找到吗？

> 追问技巧：出现"经常""有时候"→ 追问"上一次是什么时候，具体发生了什么？"
