# CampusOverflow 产品愿景 v1.0

> 负责人：PO    状态：待团队评审（评审通过后删除本行）    最后更新：2026-10-10

## 一句话愿景

为**湖北文理学院的学生、助教与教师**，解决**课程答疑散落在多个群、优质回答无法沉淀、教师无法量化学生参与度**的问题，
提供一个**按课程与班级组织、带校园身份认证与教师激励机制的校园问答平台**。

## 为什么是现在

1. 通用问答平台（Stack Overflow、知乎）无法按课程 / 教师 / 班级组织内容；
2. 课程群的答疑记录不留存，同类问题被反复提问，助教重复劳动；
3. 学院需要可量化的学习参与度作为过程评价依据。

## 目标用户与核心诉求

| 角色 | 典型场景 | 关键诉求 |
| --- | --- | --- |
| 学生 | 在《数据结构》课程中遇到红黑树旋转难题，发起带"#数据结构 #2025秋"标签的提问 | 快速获得高质量回答；通过回答他人问题积累声誉 |
| 助教 / 研究生 | 对所辅导课程的学生提问进行筛选回答，标记最佳答案 | 高效管理答疑工作量；把典型问题沉淀为知识库 |
| 教师 | 设置课程专属问答区，对优质回答给予"教师认证"标记并发放积分悬赏 | 掌握学生学习痛点；把高质量内容转化为教学素材 |
| 管理员 | 管理学院、课程、用户认证，处理违规内容举报 | 保障平台秩序与数据合规 |

## 差异化（对比 Stack Overflow）

| 能力维度 | Stack Overflow | CampusOverflow |
| --- | --- | --- |
| 账号体系 | 通用邮箱 / OAuth | 学号工号登录 + 校园身份徽章 |
| 内容组织 | 技术标签 | 课程标签 + 班级圈 + 技术标签 |
| 激励方式 | 声誉 + 徽章 | 声誉 + 徽章 + **教师积分悬赏** |
| 教师参与 | 无 | 教师认证标记、悬赏、教学素材沉淀 |
| 合规基线 | 通用隐私政策 | 对齐《个人信息保护法》《数据安全法》 |

## 成功标准（可验证）

1. 新用户 3 分钟内完成注册并发布第一个问题；
2. 提问后能看到其他用户提交的回答（端到端闭环打通）；
3. 回答被采纳后，回答者声誉值 +15 且个人主页可见变化；
4. 教师可对任意问题发起积分悬赏；
5. 系统在课程统一部署环境可访问，且核心链路有自动化测试保护。

## 明确不做（MVP 之外）

实时聊天、直播答疑、PDF 内嵌、AI 自动回答 —— 以上均为"超出 MVP"范围，仅在 Sprint 4 之后作为加分项评估，且不得影响已承诺故事的质量。

## 范围依据

本文档的"MVP 四大子域"（身份与认证 / 问答核心 / 声誉与激励 / 内容发现）来自《CampusOverflow 软件工程教学方案》2.3 节，任何新增子域都需先修订本文档。
